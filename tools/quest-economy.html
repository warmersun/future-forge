How to read this page
  1. Start a Quest — Themes, Sponsored, Learning, or Library, then a card (place + picture, not only the title).
  2. Tiles vs pathways — tiles cost Attention; a pathway is a connected island and is what eases meters.
  3. AI Attention — first AI ask of a turn is 1 AP; more thinking that turn is free. Judge/submit still costs 1 AP.
  4. Year table — one row per calendar year. Each year applies rise once (End turn). Wait is the same rise twice (usually). Whole numbers only. 5 is lose.
  5. Crisis chart — T0 is the start. Solid dots are this path’s actions (hover for the action). Dashed line: if they never invent, calendar years still climb. Pink band is red (4–5).
  6. Friends — personal Wait does not raise shared meters; table wrap (+1 year) does. The two-act Friends path uses wrap, not Wait +2.

CLI: npm run economy:quest -- path/to/quest.json. Repo guide: docs/quest-economy-lab.md.

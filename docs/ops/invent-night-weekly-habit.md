# Future Forge — Weekly Invent Night Habit OS

**Version:** 1.1  
**Purpose:** Turn “host + get the word out” into a repeatable weekly practice — not a one-off campaign.  
**You are not a student.** No official campus club required. You own the night; promotion is half the job.  
**Stack lock:** site + shares · Discord · X — not email as primary return.  
**Win definition:** people **invent once** (Spark/quest complete or clear invent artifact). Followers don’t count.  
**Night lock:** **Wednesday** every week (12-week streak). Time still open — default **18:30–19:30** local until you change it.

---

## 1. The habit (one sentence)

**Same night every week → same promotion rhythm → run even if small → capture invents → invite next week’s people from this week’s room.**

Do it once to learn the motions.  
Do it twice to prove the calendar.  
Do it every week until the night has a reputation.

## 4. Weekly rhythm (the habit loop)

```text
WED lock = NIGHT. Promo fills the week before.

THU  Plan     → next Wednesday locked, quest confirmed, event link live
FRI  Seed     → 10× 1:1 invites
SAT  Broadcast→ Reddit/Discord/X (where allowed)
SUN  Physical → boards/QR if IRL week (else skip / rest)
MON  (buffer) → optional extra 1:1s
TUE  Remind   → RSVPs + “bring laptop”
WED  NIGHT    → run · invent · capture · ask “who next?”
     Close    → same night or Thu AM: log · thanks · next link already from Plan
```

**NIGHT = Wednesday.** Do not slide the day; shrink format instead.

**Time budget (steady state): ~3.5–5 hours/week**

| Block | Minutes | When |
|-------|---------|------|
| Plan + event link | 20 | T-7 |
| 1:1 invites | 40 | T-6 |
| Broadcast posts | 30 | T-5 |
| Reminders | 15 | T-1 |
| Run night | 60–75 | T-0 |
| Log + thanks | 20 | T+1 |
| **Total** | **~3–4 hrs** | |

Protect these on the calendar like gym.

### 5.1 T-7 — Plan (Sunday)

- [ ] 1 external Discord **if mods OK** (ask once; never raid)

- [ ] Optional: Meetup.com same event  

Use **Broadcast B**.

### 5.4 T-3 — Physical (only IRL weeks)
- [ ] 10–20 QR flyers where allowed  
- [ ] Photo of room/door instructions in event page  

### 5.5 T-1 — Remind (day before)
- [ ] Ping every RSVP / soft yes  
- [ ] Send address or Discord channel + “bring laptop / charger”  
- [ ] Prep quest + AI co-inventor path yourself once (smoke test)  

Use **Remind C**.

### 5.6 T-0 — Run the night (60 min)

| Min | What |
|-----|------|
| 0–5 | Welcome, laptop open, Discord join |
| 5–10 | Pitch (60 sec) + rules: you lead, AI helps, one invent |
| 10–15 | Open https://warmersun.com/forge/ · tutorial first (help stuck people) |
| 15–50 | **Invent** (you unstick; don’t lecture) |
| 50–55 | Share one sentence of invent in `#inventions` or aloud |
| 55–60 | “Same time next week — who are you bringing?” + thanks |

**Empty-room protocol**
- 0 people: post in Discord “office hour invent — I’m on for 30” and invent publicly once (stream of work). Habit intact.
- 1 person: run full intimacy mode; treat as gold; ask for one intro.
- 3+: normal night.

**Never** cancel the calendar block because “not enough hype.” Shrink format; don’t skip week.

### 5.7 T+1 — Close (day after)
- [ ] Fill night log (section 7)
- [ ] Thank everyone who came (1:1)
- [ ] Post one invent highlight (with permission) on X or Discord
- [ ] Add new names to outreach list
- [ ] Ensure **next week’s event link** exists

## 6. Habit rules (so you don’t negotiate with yourself)

1. **Ship the week** even if promotion felt weak.  
2. **Same slot** for 12 weeks before changing day/time.  
3. **1:1 ≥ broadcast.** If only time for one promo act, do Monday invites.  
4. **Count invents, not vibes.**  
5. **One quest for a month** — stop re-prepping content as procrastination.  
6. **No new channels** until 4 nights done (no TikTok project, no email list debate).  
7. **Guest-club asks** = bonus, not a blocker. One email/week max to a club officer.  
8. After 4 weeks, review metrics once; only then change place/time/quest.

## 9. 12-week progression (habit maturity)

| Weeks | Focus | Success look like |
|-------|--------|-------------------|
| 1–2 | Install the calendar + promo muscles | Night happens twice; ≥1 invent total |
| 3–4 | Tighten 1:1 list; same quest | ≥1 show-up most weeks |
| 5–8 | Returners + “bring one friend” | 1 returner or 3+ invents some weeks |
| 9–12 | Optional IRL upgrade or 1 campus guest slot | Night has a tiny reputation; you stop reinventing process |

**Do not** found four official campus clubs in weeks 1–4.

---

## 10. Streak protection

| Threat | Counter |
|--------|---------|
| “Nobody RSVP’d” | Run office-hours invent online anyway |
| Overbuilding content | Freeze quest for 4 weeks |
| Promo shame | Script is already written — send bad DMs > perfect silence |
| Travel week | Pre-announce online-only; don’t skip |
| Burnout | Cap at time budget; cut physical flyers first, never cut 1:1 + night |
| Shiny channel | Park it in a note until week 12 review |

**Streak rule:** a week counts if (a) promo seed OR broadcast happened **and** (b) the night block was attended by you in host mode.

---

## 11. Quarterly review (30 min)

Every 12 weeks:
1. Total invents · avg show-ups · returner rate  
2. Keep / change: day, time, place, quest  
3. One distribution upgrade only (e.g. first club guest night)  
4. Still no email-primary; still invent-first messaging
